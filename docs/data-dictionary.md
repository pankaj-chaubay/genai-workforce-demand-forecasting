# Data dictionary

All data in `data/synthetic/` is generated by `src/workforce_forecast/synthetic.py`. No row describes a real person or project.

## hr_hiring_extract.csv

One row per hire, shaped like a typical HRIS export. Some columns are there only so the privacy controls have something to remove.

| Column | Description | Reaches the model |
|---|---|---|
| employee_id | Sequential ID | No. Replaced by a salted hash (`person_key`) |
| email | Fake address on example.com | No. Dropped |
| hire_date | Date of hire | As hire month |
| leave_date | Date of leaving, empty if still employed | No |
| technology | solar or wind | Yes |
| country | DE or ES | Yes |
| role_family | engineer, technician, project_manager, admin | Yes |
| contract_type | permanent or temporary | Kept in model records, not used as a feature |
| gender | F or M | No. Aggregated audit only |

## project_pipeline.csv

| Column | Description |
|---|---|
| project_id | Project key |
| technology, country | Where the project sits |
| development_start | Month development work starts (6 months before construction) |
| construction_start | Month construction starts |
| construction_months | Length of construction |
| capacity_mw | Planned capacity |

## How the data was generated

* Project starts follow a Poisson process per technology and country. A solar subsidy in DE raises starts in 2023-2024; a tariff cut in ES lowers them from 2025.
* Monthly hires per segment follow a Poisson distribution whose rate depends on the role's pipeline driver, the season, policy effects, a post-COVID backlog in 2022 to mid-2023 for engineers and technicians, and random noise.
* The stakeholder file holds estimates of these effects, not the true values, the same way real experts would.
